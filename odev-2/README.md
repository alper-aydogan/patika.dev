# Odev 2 - Post Siralama ve Post Ekleme

Bu odevde konsol ekraninda once mevcut postlar listelenir, sonra yeni bir post eklenir ve postlar tekrar listelenir.

## Calistirma

```bash
node index.js
```

## Ornek Cikti

```txt
Mevcut postlar:
Post 1
Post 2
Post 3
Yeni post eklendikten sonra:
Post 1
Post 2
Post 3
Post 4
```
