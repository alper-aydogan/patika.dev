# Odev 4 - FS File System Modulu

Bu odevde Node.js `fs` modulu kullanilarak `employees.json` dosyasi uzerinde CRUD islemleri yapilir.

## Islemler

- `employees.json` dosyasi olusturulur.
- Dosyaya employee verisi eklenir.
- Dosyadaki veri okunur.
- Veri guncellenir.
- Dosya silinir.

## Calistirma

```bash
node index.js
```
